INTRODUCTION                                                      *cvs-intro*

cvs.nvim is a Neovim-native CVS workflow plugin.

The main status and file-diff workflows follow the corresponding Fugitive
commands while keeping CVS semantics.

==============================================================================
COMMANDS                                                        *cvs-commands*

                                                          *:Cvs*
:Cvs[!] [path]
        Open the themed CVS status view in a horizontal split. Move to a file
        and press <CR> to open it in the original editing window. Use o, gO, O,
        or p to open it in a horizontal split, vertical split, tab, or preview.
        Press dd for a full diff against the checked-out revision, or = on a
        modified file to toggle its inline unified diff. Press - on a file,
        visual range, or section heading to toggle the commit selection. Press
        a on an unknown or removed file, visual range, or section heading to
        add or restore the eligible files. Press A on an unknown file, visual
        range, or the Unknown heading to add files in binary mode with -kb.
        Press cc to open a commit message buffer for the selected files.

        Status queries run asynchronously. The buffer opens immediately with
        a loading message, and refreshes keep the previous snapshot visible
        while CVS runs. Refreshes preserve the file under the cursor when it
        remains in the result. A recent cached snapshot is reused when
        possible. Cached snapshots expire after five minutes and are discarded
        when a working-copy buffer is written. Use [!] or press R in the status
        view to query CVS again immediately.

                                                         *:CvsStatus*
:CvsStatus[!] [path]
        Alias for the CVS status view used by |:Cvs|.

                                                        *:CvsUpdate*
:CvsUpdate [path]
        Open the scaffolded update workflow.

                                                         *:CvsAdd*
:CvsAdd [path]
        Add the current buffer or the provided path to CVS.

                                                         *:CvsRemove*
:CvsRemove [path]
        Schedule the current buffer or the provided path for CVS removal.

                                                         *:CvsCommit*
:CvsCommit [path]
        Open a direct CVS commit message buffer for the current workspace or
        path.

                                                         *:CvsDiff*
:CvsDiff [path]
        Diff the current or provided working file against its checked-out CVS
        revision in a vertical split.

                                                        *:Cdiffsplit*
:Cdiffsplit
        Diff the current working file against its checked-out CVS revision in
        a vertical split. The working buffer remains editable, including any
        unsaved changes; the CVS base buffer is read-only.

                                                        *:CvsLog*
:CvsLog [path]
        Open the scaffolded log workflow.

                                                        *:CvsAnnotate*
:CvsAnnotate [path]
        Open the scaffolded annotate workflow.

                                                        *:CvsConflicts*
:CvsConflicts [path]
        Open the scaffolded conflict workflow.

==============================================================================
CONFIGURATION                                                      *cvs-config*

Status snapshots are cached for five minutes by default. The cache can be
configured through setup():
>
    require("cvs").setup({
      status = {
        cache = {
          enabled = true,
          ttl_ms = 300000,
        },
      },
    })
<
Set enabled to false to always query CVS. A ttl_ms value of 0 also prevents
cache reuse. Regardless of these settings, the [!] form of |:Cvs| and R in the
status view force an immediate refresh.
